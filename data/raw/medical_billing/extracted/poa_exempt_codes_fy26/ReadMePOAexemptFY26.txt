Description of Present On Admission (POA) files

List of Present On Admission (POA) exempt codes, for FY2026 (38,349 codes).
POAexemptCodesFY26.xlsx (Excel spreadsheet)
POAexemptCodesFY26.txt (tab delimited text)
These files have three fields, as below.
Order26: a number as text (with leading zeros), corresponding to the code ordering in the classification, and in the descriptions list file, for FY2026.
POAexemptCode: the ICD-10-CM code that is exempt from POA reporting.
Description: the long title for the ICD-10-CM code, corresponding to the descriptions list file.

List of codes added to the current FY2026 POA exempt list, from the previous list, to properly match the guidelines (209 codes).
POAexemptAddCodesFY26.xlsx (Excel spreadsheet)
POAexemptAddCodesFY26.txt (tab delimited text)
These files have three fields, as below.
Order26: a number as text (with leading zeros), corresponding to the code ordering in the classification, and in the descriptions list file, for FY2026.
POAexemptCode: the ICD-10-CM code that has been added to the previous list.
Description: the long title for the ICD-10-CM code, corresponding to the descriptions list file.

List of codes deleted from the previous POA exempt list, to create the current FY2026 POA exempt list (14 codes).
POAexemptDeleteCodesFY26.xlsx (Excel spreadsheet)
POAexemptDeleteCodesFY26.txt (tab delimited text)
These files have two fields, as below.
POAexemptCode: the ICD-10-CM code that has been removed from the previous list.
Description: the long title for the ICD-10-CM code, corresponding to the descriptions list file.

List of codes revised from the previous POA exempt list, to create the current FY2026 POA exempt list (25 codes, listed twice as Revise from and Revise to, for 50 lines).
POAexemptReviseCodesFY26.xlsx (Excel spreadsheet)
POAexemptReviseCodesFY26.txt (tab delimited text)
These files have four fields, as below.
Order26: a number as text (with leading zeros), corresponding to the code ordering in the classification, and in the descriptions list file, for FY2026.
Action: "Revise from:" and "Revise to:" showing the previous title and the new title, respectively.
POAexemptCode: the ICD-10-CM code that has been revised from the previous list.
Description: the long title for the ICD-10-CM code, corresponding to the descriptions list file.
